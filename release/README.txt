NZP Web Co-op for Windows

1. Duckmath room: use NZP-Duck. nzp.gay room: use NZP-Web.
2. Add the game files listed in nzp\GET-GAME-FILES.txt.
3. Run nzportable64-dtlsclient.exe.
4. Co-operative, server browser, refresh, join an unlocked room.
5. Kicked with "Map model file does not match"? Use the other folder.

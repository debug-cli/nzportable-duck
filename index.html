nzportable-duck

Join Nazi Zombies: Portable browser co-op rooms (nzp.gay, Duckmath) from the native Windows game. Everything runs in this page. Nothing is uploaded.

1Get the official exe

Download pc-nzp-win64-nosdl.zip from nzp-team, then extract nzportable64.exe.

Use the nosdl zip. The SDL exe (nzportable-sdl64.exe) cannot join web rooms.

2Patch it

Waiting for a file.

3Get the config files

Put these next to the exe. autoexec.cfg goes inside the nzp folder.

identity.pfx

identity.pfx is a shared, throwaway RSA certificate that is known to work with Windows. It is not a secret. You can delete it, and the game makes its own.

4Add the game data for the host

The game files must match the room's host. Make one folder for each.

nzp.gay rooms: game.pk3 and progs.pk3

Duckmath rooms: nzp_game.pk3 (rename it to game.pk3), plus progs.pk3 from the nzp folder of Duckmath's game page.

Do not extract .pk3 files. If your browser saves one as .zip, rename it back to .pk3.

NZP-Web\
  nzportable64-dtlsclient.exe
  default.fmf
  identity.pfx
  nzp\autoexec.cfg
  nzp\game.pk3
  nzp\progs.pk3

5Play

Run nzportable64-dtlsclient.exe. Go to Co-operative, then the server browser, then refresh, and join an unlocked room.

Kicked with "Map model file does not match"? Use the other data folder.
